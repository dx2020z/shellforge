# 游戏感改造方案（2026-09-25）

## 为什么现在看着不想玩

1. **目前能看到的只有组件目录。** `/design` 是设计系统的零件陈列，真正的游戏画面（工坊、锻造、擂台）要到 P3 才做。但反馈是对的：现有视觉语言偏「深色后台」——面板、小字、标签多，角色和光效少。
2. **最好看的东西没上屏。** 旧项目里已经生成了 19 套卡通造物（见 `docs/design/legacy-models-sheet.png`），很有魅力，但旧版把它们塞在侧栏的小视窗里。
3. **旧版 3D 发糊。** 旧版把渲染像素比固定为 1 并关闭抗锯齿（`CreatureScene.tsx`），在 3 倍屏手机和 Windows 125%/150% 缩放的笔记本上画面会被拉伸。新版已加 `src/three/quality.ts`：按设备像素比渲染，掉帧再逐级降档。
4. **进门到开玩太慢。** 旧版首屏是三栏表单，要先读说明才知道做什么。

## 改法

| 方向 | 具体做法 |
|---|---|
| 首屏即游戏 | 打开就是被灯光照亮的海底洞穴，中央一只造物在呼吸、眨眼，底部一个输入框。10 秒内能开始锻造 |
| 角色是主角 | 造物占屏幕 50–60%，镜头自动取景；待机动画、点它会有反应；UI 全部浮在场景上，不再用面板分栏 |
| 手机与电脑同一构图 | 手机竖屏：上方薄 HUD，下方行动托盘在拇指区；电脑：场景更大，键盘 1–4 出招，悬停即预览后果 |
| 更亮、更有层次 | 保留深海底色，加生物荧光（珊瑚粉、灯笼黄）、光束、景深雾、前景海草剪影视差、气泡粒子 |
| 打击感 | 命中停顿、伤害数字弧线弹出、受击部件闪白、镜头轻震、完美应对慢动作、五声音阶音效 |
| 少读字 | 意图用图标 + 一句话；行动卡只写「你将受到 X · 守卫受到 Y」；教学用高亮代替长说明 |
| 用上已有资产 | 13 套可用的旧生成造物：做首页「海底标本馆」展示可以造出什么、做离线示例造物、挑几套当守卫，省掉部分 Tripo 调用 |

## 建议的下一步：先做「可玩样板」

原计划 P2 只做规则引擎、不做界面，要到 P3 才能看到游戏画面。建议改为：

**样板关 = 工坊 → 锻造仪式 → 对阵教学守卫的一场战斗**，全屏 3D、动画、音效齐全，手机和电脑都能玩。战斗 v2 的核心规则同时实现（数值平衡与 `npm run sim` 验收放到之后）。这样最快能判断「好不好玩、好不好看」，方向不对也能早改。

## 进度（2026-09-25 晚）

**样板关已完成**：工坊 → 锻造仪式 → 一命提示 → 教学战斗（新手引导高亮）→ 胜利缴获 / 继续下潜 / 回港 → 死亡墓志铭与失败复盘 → 传承给下一代。截图在 `docs/screens/flow/`（手机竖屏、横屏、桌面三套）。

- 战斗 v2 规则引擎：`src/domain/battle.ts`，7 位守卫：`src/domain/guards.ts`，79 个单元测试通过。
- 13 套旧生成卡通模型压缩后进入游戏（每件约 0.4 MB）：7 套当守卫，其余组成离线部件库，没有 Tripo 时按原话挑选外观；配置了 Tripo 会在后台生成专属部件并热替换。
- 7 种尺寸巡检全部通过；手机横屏有单独的左右布局。

**第二轮（地图、造物卡、打磨）已完成**

- 远征地图（`src/scenes/ExpeditionMap.tsx`）：7 位守卫排在一条海沟里，未到的是剪影；当前一站显示谜语、克制关系（「因为你写了「…」，它会怕你」）和侦察情报。生命值在一次远征里延续。
- 潮汐泉（`src/scenes/TidalSpring.tsx`）：每胜一场三选一——回复一半生命 / 给一件部件加一道印记 / 侦察下一位守卫的完整出招顺序（战斗里会显示「接下来」三回合）。
- 造物卡（`src/domain/card.ts` + `src/ui/card-render.ts`）：离屏渲染透明底标本照，Canvas 画 1080×1920 竖图，可保存或分享；长眠的造物带墓志铭和「已长眠」印章。
- 图鉴（右上角书本图标）：按血脉分组，死去的造物也在，任意一只都能导出造物卡。
- 打磨：开场 VS 对决卡、重做的行动卡（承受 / 造成两个大数字、完美应对金色飘带）、受击火花、场景切换潮水、输入时实时弹出能力徽章、工坊里可以拖动旋转造物、轻点它会跳。

**第三轮：核心玩法改成「写字对决」（样板：铜甲斥候）**

- 规则引擎 `src/domain/duel.ts`：话语卡（来自原话，每句一次）、墨水临场写一句（动作词优先读懂）、守卫意图只给词和一句话、三道谜语（弱点 / 死角 / 秘密）。
- 场景 `src/scenes/DuelScene.tsx`：文字飞出、撞击、护盾、闪避、守卫出招文字、谜语解开横幅、开场对决卡带谜语。
- 流程：工坊显示三道谜语 → 锻造 → 一命提示 → 对决 → 胜利（谜语进度、再战一次）/ 长眠与传承。地图和潮汐泉的代码还在，样板阶段暂时不走。
- 截图：`docs/screens/duel/`。

**第四轮：守卫库与名册**

- `src/domain/duel-guards.ts`：6 位预设守卫（弱点 / 抗性 / 死角 / 秘密各不相同）；长眠造物自动变成亡者守卫；`nextDuelGuard` 保证打败一位后一定换一位新的，赢过之后优先遇到还没打过的亡者守卫。
- 守卫定义随对决存进存档（纯数据）。话语卡说过后歇两回合；解开谜语墨水 +1。
- 名册：最多 5 只活着的造物，长眠的不占名额；死后可传承一件部件，也可以不传承直接离开。
- 平衡模拟：`npx tsx scripts/duel-sim.ts`。
