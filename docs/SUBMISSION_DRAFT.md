# ShellForge · 造物之海｜参赛提交草稿

参赛主题：Tripo 命题。参评赛道：**NEW LIFE · AI 游戏与交互世界**。游戏名称中的 ShellForge 与主办方另设的硬件赛道 SHELL FORGE 同名，但本作品是 AI 游戏。

## 项目介绍

玩家在一页中描述想要的头、身体和脚。DeepSeek 把三段想象整理成一只风格统一的造物设定；Tripo 为三件分别生成真实 3D 模型。玩家将它们装配、旋转查看、与遗迹守卫自动战斗。获胜可缴获敌人的部件蓝图；失败可选择一件部件传承给下一代。游戏保留本地进度，生成模型下载到本机，界面显示真实任务状态。

我们希望让玩家创造的东西直接进入游戏循环，经历战斗、失去和传承。当前版本已打通文字设定、3D 生成、三槽位装配与单机战斗；生成外观仍沿用所选蓝图的固定属性与技能，尚未实现描述驱动战斗规则。演示时会如实区分实时生成的部件与预置美术。

## 技术说明

Next.js 16、React 19、Three.js。DeepSeek Chat Completions 一次产出三个受白名单约束的部件草案；Tripo v3 分别提交异步任务。服务端保存任务编号与 GLB，并限制下载域名、模型格式和文件大小；浏览器保存玩家进度和任务展示状态。模型或网络失败时，已导入的预置 GLB 和程序化外观继续支撑游戏。
